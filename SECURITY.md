# Security policy

## Supported versions

Inbox Strata is pre-1.0. Security fixes are applied to the latest release and the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue containing mailbox data, credentials, exploit details, or personal information.

Include the affected version, impact, reproduction steps using fictional data, and any suggested mitigation. Please do not test against mailboxes or accounts you do not own or have explicit permission to access.
